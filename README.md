# The Pendant — published website

Static website files for the Studio 01 jewellery concept, published through GitHub Pages.

The page contains a scroll-controlled 3D pendant, generated product imagery, detail and worn views, and an interactive image viewer. Three.js is used under the MIT license included in `vendor/THREE-LICENSE.txt`.

This repository contains the files served by the website. The editable project and Blender model are maintained separately.

Studio 01 is a working identity. Product imagery and unseen 3D construction are illustrative; confirmed specifications, dimensions, and commercial details have not been supplied.
